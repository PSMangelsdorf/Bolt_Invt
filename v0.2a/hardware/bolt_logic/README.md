# bolt_logic — KiCad project

Replacement logic board for the Chevrolet Bolt EV traction inverter.

## Current state (v0.2a — redesign after the forum review)

- **Schematic v0.2a:** 7 hierarchical sheets, 245 parts, 162 nets, drawn as wired sheets in
  signal-flow order.
  - PDF: `../../docs/bolt_logic_schematic.pdf`
  - Design rationale: `../../docs/03-schematic-design.md`
  - What changed and why: `../../docs/06-forum-review.md`
- **PCB v0.2a:** 4 layers (signal / GND / power / signal), placed and routed. Prototype for
  review; see `../../docs/04-layout.md`.

## Regenerating

Everything is generated by scripts; edit the tables, not the outputs. You need KiCad 7+
(`pcbnew` Python module and `kicad-cli`). Routing also needs Java 21, `xvfb-run`,
FreeRouting 1.9 (`FREEROUTING_JAR`) and `shapely`.

```
python3 tools/gen_sch.py      # schematic sheets from tools/sch_design.py + sch_layout.py, netlist verified
python3 tools/gen_mech.py     # outline, holes, CN1/CN2 (asserts every pad position)
python3 tools/gen_layout.py   # netlist -> footprints, pad cross-check, placement
python3 tools/gen_route.py    # planes, buck / crystal / contactor copper, plane fan-out, FreeRouting, pours, DRC
python3 tools/gen_fab.py      # fab/: Gerbers + drill zip, JLCPCB BOM + CPL, full BOM, fab notes
```

`gen_route.py` takes about 10–15 minutes, most of it FreeRouting. Its working files go to
`route_work/` (not committed):
- `--import-only` re-imports the last routing run.
- `--stage2-only` keeps stage 1 and redoes only stage 2.

## Files

- `bolt_logic.kicad_pcb`: generated; don't hand-edit the mechanical items. Hand-tuning of
  the routing (see the review list) is expected later. Once that starts, stop re-running
  `gen_route.py`, because it would overwrite the hand edits.
- `tools/gen_mech.py`: single source of truth for mechanical dimensions.
- `tools/sch_design.py`: the schematic design table (every part, every pin → net).
- `tools/sch_layout.py`: where each symbol is drawn on its sheet, label directions, section notes.
- `tools/gen_layout.py`: placement regions (`GROUPS`), anchors, decoupling pairs (`NEAR`), the 10 mm CN1/CN2 clearance and the height check.
- `tools/gen_route.py`: net classes, In2 power-plane islands, routing flow, GND stitching, chassis ring.
- `tools/buck_block.py`: the hand-designed 5 V buck block (placement and copper).
- `tools/jlc_parts.py`, `tools/gen_fab.py`: proposed LCSC part per BOM line, and the fab package.
- `tools/gen_cn1_compare.py`: writes `../../docs/cn1_oem_vs_new.pdf`, the CN1 OEM-vs-new pin table.
  Re-run it after changing CN1 assignments in `sch_design.py`.
- `Bolt.pretty/`, `Bolt.kicad_sym`: project footprint and symbol libraries.

Coordinate frame and measurement provenance: `../../docs/02-mechanical.md`.
The project is saved in KiCad 7 format. It opens in KiCad 8/9, which will offer to upgrade
the file.
