# Bolt_Invt
Open Source drop in logic board for Chevrolet Bolt inverter, based on the collective work of the Open Inverter Project, and especially that of Damien Maguire.

October 10, 2026 - Establishing repo for logic board development.  External pinout established from GM service information.  Internal pinout between logic and gate boards established via probing and tracing.

October 11, 2026 - Initial design completed by Claude - WARNING: This design is completely untested at this point.  ADDITIONAL WARNING: This design does not support the OEM Bolt drive motor/transmission at this time.  It does not drive the pump or read the IMS position.  It has not been configured with the Bolt resolver or temp sensors.

October 31, 2026 - A few updates made to the 5V regulation by Claude, also used Claude to produce gerbers and BOM.  First prototypes have been ordered.
